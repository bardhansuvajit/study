PYTHON BASICS install python & check version ---->>>> python -V (OP - Python 3.14.5) Conda - a package + environment manager, especially popular for ML/data science because it handles non-Python dependencies too (like CUDA, MKL, etc.), which pip can't do. PIP/ Pip Installs Packages - Python's default package manager PyPI/ Python Package Index - like an App-Store for Python Libraries e.g. - pip install numpy > Someone writes a library → uploads it to pypi.org. We run pip install → pip fetches it from there pip vs. conda > pip installs python packages only conda installs python packages + system level stuffs (C libraries, CUDA etc.) > gets packages from PyPI gets packages from Conda repos How to install conda ? - Use Miniconda instead of full Anaconda, Follow this link https://www.anaconda.com/download/success?utm_source=chatgpt.com TRY IN ANACONDA CMD, (base) C:\Users\user> ---->>>> conda --version (OP - conda 26.3.2) Open Anaconda Prompt, (base) C:\Users\user>E: (base) E:\>cd Projects\Python (base) E:\Projects\Python>ls project-1 (base) E:\Projects\Python> Now inside E:\Projects\Python> ---->>>> conda create --name ai-env python=3.12 This means, conda create → using CONDA tool create a new isolated environment (separate from main system) --name ai-env → name it "ai-env" python=3.12 → install Python 3.12 inside it (many AI libraries may not support 3.14 yet) OR ---->>>> conda create -p venv python==3.12 This is BETTER, means, CREATE a folder named venv in current directory & create the environment inside the project folder as a subfolder called venv/. **** This is common in professional/team projects so the environment stays with the code. ---->>>> conda activate venv/ This means, From now on, use Python and libraries inside THIS environment. Without activation: terminal uses Base environment/ Conda's default Python 3.14, now check, python --version. NOW, the CMD becomes, (E:\Projects\Python\project-1\venv) E:\Projects\Python\project-1> JUST a SIMPLE TEST, create app.py in root, print(1+1) ---->>>> (E:\Projects\Python\project-1\venv) E:\Projects\Python\project-1>python app.py (OP 2) Jupyter Notebook writing code in small chunks called "cells" & run them one at a time. In normal Python, we write code in .py file & run the whole file at once .ipynb Interactive Python Notebook. It's the file format Jupyter uses WHY ? This is huge in data science/ML because we do things step by step.If Cell 3 has a bug, we fix ONLY Cell 3 and re-run it. No need to reload the dataset again. Saves massive time. DIFFERENT PYTHON ENVIRONMENTS Other than conda, ther are ways to install Python projects. ALways create ISOLATED box for projects. So libraries don't mix with each other #Method 1. Built-in Python python -m venv myenv # CREATE isolated environment, name it "myenv" myenv\Scripts\Activate # ENTER the environment (Windows) pip install numpy # INSTALL libraries inside it deactivate # EXIT the environment -m means → "run this as a module". Python comes with a built-in module called venv, just telling Python to use it. #Method 2. VIRTUALENV (Third Party Tool) pip install virtualenv # INSTALL virtualenv tool first (doesn't come with Python) virtualenv -p python3 virtual_env # CREATE environment, specifically using python3 virtual_env\Scripts\activate # ENTER the environment deactivate # EXIT the environment #Method 3. CONDA conda create -p venv python==3.12 -y # CREATE environment in current folder with Python 3.12 # -y means "yes to everything, don't ask me to confirm" ######################################## 2.
