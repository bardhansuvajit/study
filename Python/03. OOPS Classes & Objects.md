Object-Orinted programming is a programming paradigm that uses "objects" to design applications and computer programs. OOP allows remodeling real-worls scenarios using classes & objects. 

**** CLASS & OBJECT ****
a blueprint to create objects

Example - 
class Car:
    pass                >>>> Python requires something inside a class, function, if, etc. If you don't have anything to write yet, you can use pass as a placeholder.

audi = Car()
print(type(audi))       >>>> <class '__main__.Car'>
print(audi)             >>>> <__main__.Car object at 0x000002B5280A1FD0> - the car object is at this menory location
audi.windows = 4
print(audi.windows)     >>>> 4

 **** CONSTRUCTOR ****
## Instance Variable & Method
class Dog:
    ## Constructor
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f"{self.name} says woof")

## Create Object
dog1 = Dog("Cupcake", 3)
print(dog1)
print(dog1.name)
print(dog1.age)
dog1.bark()

Output:
<__main__.Dog object at 0x00000212FEDF6840>
Cupcake
3
Cupcake says woof
